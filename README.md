# Fragments of Pleasure

An interactive generative artwork exploring the “dopamine trap” in fragmented digital behaviour through real-time user interaction.

---

## Concept

In contemporary digital environments, people are increasingly accustomed to short, fragmented forms of stimulation — scrolling, clicking, and rapid content consumption.
While these interactions provide instant gratification, they often lead to a sense of emptiness and loss of focus.

This project visualises this phenomenon as a dynamic system, allowing users to experience the cycle of stimulation and withdrawal through interaction.

## System Overview

The project is built as an interactive generative visual system:

* A grid of rectangles forms a brain-like visual structure
* Visual elements dynamically change in colour, size, and position
* Each interaction triggers a burst of visual activity
* The system gradually returns to a static state after each cycle

This loop simulates the pattern of short-term stimulation followed by a return to emptiness.

---

## Interaction Design

* **Mouse click** → triggers dynamic visual change
* **Repeated interaction** → prolongs the active state
* **Idle state** → system returns to baseline

User behaviour directly influences the duration and intensity of the system response, reflecting patterns of digital engagement and dependency.
